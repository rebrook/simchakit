What changes

  • The display-name modal folds into account setup after the first event is created, with "Skip for now" as the default path to the event.
  • Sub-events seeded by event type (editable). A mitzvah suggests service, kiddush and reception; a wedding suggests ceremony and reception.
  • Checklist state moves from localStorage to the event record.
  • Missing email is flagged at import because guest messaging in v5 needs it.
  • Admin keeps themes, roles, data and export; first run never requires it.
