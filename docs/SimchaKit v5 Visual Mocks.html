Design notes

  • Status words and shapes carry meaning; green and red are never the only cue (Yes and No are labeled).
  • Guest pages take the event palette and logo, and follow the dark-mode token set.
  • Needs-you list uses the same button and dot language as the Gifts chips, so status reads the same on every screen.
  • All guest-page controls are at least 44px tall.
